# Атмосфера — оболочка для Haier ATV (Android TV 11)

## Честный статус
- Весь исходный код написан и лежит в этом архиве (Kotlin, нативный Launcher, без WebView).
- **APK я не собирал**: в моей среде нет Android SDK, Gradle и интернета. Код не был скомпилирован и не тестировался на телевизоре. Возможны мелкие ошибки сборки — если они появятся, пришлите мне текст ошибки, и я исправлю.
- Что именно нужно сделать вам: получить APK (шаг 1) и установить его (шаг 2 или 3).

## 1. Как получить APK (выберите один способ)

### Способ А. Бесплатная облачная сборка на GitHub (без установки программ)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository, Private).
2. Распакуйте ZIP на компьютере. Загрузите ВСЕ файлы в репозиторий (Add file → Upload files), включая скрытую папку `.github`.
   Если папка `.github` не загрузилась: создайте файл `.github/workflows/build-apk.yml` через «Add file → Create new file» и вставьте содержимое из архива.
3. Откройте вкладку Actions → Build APK → Run workflow. Через 3–6 минут сборка завершится.
4. Откройте завершённую сборку → внизу «Artifacts» → скачайте `AtmosphereTV-apk` (внутри `app-release.apk`).

### Способ Б. Android Studio (на ПК)
File → Open → папка проекта → дождаться синхронизации → Build → Build APK(s). Файл: `app/build/outputs/apk/`.

### Способ В. Попросите знакомого разработчика
Команда: `gradle assembleRelease` (Gradle 8.7, JDK 17).

## 2. Установка через USB-флешку
1. Скопируйте `app-release.apk` на флешку (FAT32/exFAT), вставьте в ТВ.
2. Установите на ТВ любой файловый менеджер из Google Play (например, X-plore или File Commander).
3. Откройте флешку → APK → «Установить». При запросе разрешите «Установку из неизвестных источников» для этого менеджера (Настройки → Приложения → Особый доступ).

## 3. Установка через ADB (с компьютера)
1. На ТВ: Настройки → Устройство → О устройстве → 7 раз нажать «Сборка». Затем Настройки → Устройство → Для разработчиков → включить «Отладка по USB / по сети».
2. Узнайте IP телевизора (Настройки → Сеть). На ПК (установлены Android platform-tools):
```
adb connect IP_ТЕЛЕВИЗОРА:5555
adb install -r app-release.apk
```
3. На ТВ подтвердите запрос отладки.

## 4. Сделать «Атмосферу» главным экраном
1. Нажмите кнопку Home на пульте. Если появится выбор — выберите «Атмосфера» → «Всегда».
2. Если выбора нет (на многих прошивках его нет), выполните через ADB:
```
adb shell cmd package set-home-activity com.atmosphere.tvhome/.MainActivity
```
3. Нажмите Home — должна открыться «Атмосфера».
Ограничение: на некоторых прошивках Haier кнопка Home жёстко открывает стандартный экран. Тогда запускайте «Атмосфера» из списка приложений. Я не могу проверить заранее, как поведёт себя ваша прошивка.

## 5. Автозапуск при включении
Основной способ — шаг 4: после включения ТВ система открывает Home-приложение, то есть «Атмосферу». Запасной вариант: приложение просит запуск при загрузке, но Android 10+ часто запрещает запуск из фона. Опасных обходов (root, отключение системных приложений) я не использую.

## 6. Вернуть стандартный интерфейс
- Самый надёжный способ: удалить приложение (в «Атмосфере» кнопка «Настройки ТВ» → Приложения → Атмосфера → Удалить, либо `adb uninstall com.atmosphere.tvhome`). Стандартный экран вернётся сразу.
- Либо Настройки → Приложения → Приложения по умолчанию → Главный экран (если есть в вашей прошивке).

## 7. Погода
API-ключ **не нужен**: используется бесплатный Open-Meteo. При первом запуске выберите «📍 Город» и введите название (экранная клавиатура), затем выберите из списка. Обновляется каждые 30 минут. Без интернета показывается «Нет связи», выдуманных данных нет.

## 8. Управление пультом
- Стрелки — перемещение, OK — запуск/выбор, Back — закрыть панель (на главном экране ничего не делает).
- Удерживание OK на приложении (или кнопка Menu) — добавить/убрать из избранного.
- Кнопка Menu вне приложения — открыть «Атмосферу».

## 9. Атмосферы и эффекты
Новый год, Дождливый день, Уютный вечер, Зима, Облачно, Ночь, Светлая, Тёмная. В панели «Атмосфера»: предпросмотр, интенсивность анимаций (при «Выключено» — статичный фон), снег, дождь, декор, свечение. Настройки сохраняются после перезагрузки.
Добавить тему: в файле `AtmosphereTheme.kt` скопируйте любой блок в списке `Themes.all` и измените цвета и флаги.

## Что не проверено
Сборка, внешний вид на реальном экране, плавность на процессоре Haier, поведение кнопки Home на вашей прошивке.
